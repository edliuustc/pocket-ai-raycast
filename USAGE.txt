Pocket AI - your AI tools in Raycast

MAC INSTALLATION
See INSTALL-MACOS.md for source import, provider setup, Mac shortcuts,
updates, and required desktop checks. Mac Raycast V1 installation is
user-reported; the latest UI changes are not maintainer-verified on Mac.
Do not run install.ps1 on a Mac.
The Ctrl shortcuts below describe Windows; use the Mac guide for equivalents.

QUICK START
Type an alias, press Space, enter your text, then press Enter:
  ask  Ask anything
  df   Define a word or phrase
  tr   Translate text
  pl   Polish text

Rich Markdown replies stream directly into the native preview. Actions >
Use Full-Width Text switches to the original row-based stream; Show Rich
Markdown switches back. Set your default in native Response View preferences.
Markdown image URLs are supported, not binary attachments or a web canvas.
That bar clears automatically and
becomes the follow-up input. Type another instruction and press Enter to
continue the same conversation. Previous questions and answers stay visible.
New Conversation starts over; Regenerate Last Response retries without
duplicating the last question. The model dropdown is at the top right.

Full-width text follows the latest streamed line. Rich mode follows messages;
Raycast V1 does not expose control of scrolling inside the Markdown pane,
so long rich replies use native/manual scrolling. Pause explicitly before
browsing older transcript rows so you can read without being moved.
Ctrl+L pauses auto-scroll, or jumps to the latest line and resumes it.
Sending a new follow-up always resumes following the newest answer.
Raycast does not expose wheel-scroll events to extensions: use Ctrl+L to
pause before browsing with only the mouse wheel.

CUSTOMIZE EACH COMMAND
Run Pocket AI Settings. Select any command and press Enter to edit it.
Add New Command is the first visible entry; AI Provider opens endpoint/key
preferences. Every command has Delete Command in its Actions and editor.
Deleted built-ins can be restored with their previous settings from the
Deleted Built-in Commands section. Custom command deletion is permanent.
Raycast's static built-in command rows and manually created Quicklinks are
host-owned: disable/remove their shortcut entries in Raycast Settings if
you do not want them listed there. Deleted commands cannot run.

From any open command, use Actions > Pocket AI Settings (Ctrl+Shift+,),
or Customize This Tool (Ctrl+E) to edit just that command.
This dashboard is separate from Raycast's native extension preferences,
which support provider and remote-agent preference fields, not arbitrary
command-management controls.
You can change its title, system prompt, input placeholder, follow-up
placeholder, model override, and optional API endpoint override.
Each built-in command starts with its own prompt and placeholders. Restore
Default Prompt and Restore Default Placeholders are in the settings Actions.
Placeholders apply to the open command's top input bar. Raycast defines the
root argument hint in its static manifest, so that hint does not change.

TRANSLATOR
No target language is preselected and there is no global translation
language. Choose a language inside Translator, or set Translate Into in
that command's Customize This Tool screen. Your explicit choice is saved
for that command. Other Language lets you enter any language.

CONNECT YOUR AI PROVIDER
Run Configure AI Provider from Raycast, or from a command's Actions:
  API Endpoint: an OpenAI-compatible base URL ending in /v1, or its full
                /chat/completions URL
  API Key:      the provider's key, without the word Bearer

The existing local provider is already configured:
  http://127.0.0.1:23333/api/openai/v1
Leave API Key empty if your provider does not require authentication.
Keep the provider app/server running. Models are discovered automatically.
Keys belong only in the password field, never in URLs or system prompts.
Different-origin endpoint overrides do not receive the default API key.
No Raycast Pro or paid Raycast AI API is required.

OPTIONAL REMOTE AGENTS
In Pocket AI Settings > Remote Agents, choose Hermes Agent or OpenClaw Agent
as the Ask AI Backend. Only that backend's fields appear. Enter its server URL
and Save Settings; switching keeps both URLs. Use Actions > Set Hermes API Key
or Set OpenClaw Gateway Token / Password for its native secure password field.
Raycast's separate native preferences screen always lists all advanced fields.
Reopen Ask AI and choose an advertised agent from the dropdown.
Direct Model stays the default; Dictionary, Translator, Polish, and custom
tools keep their direct provider. See REMOTE-AGENTS.md for server setup,
SSH/private ingress, OpenClaw device pairing, and supported protocol versions.
Remote tools and history live on the agent machine. Closing the view detaches
without cancelling remote work. Stop Remote Run sends a remote cancellation;
Reconnect and Resume reloads the same session without resubmitting its task.

CREATE YOUR OWN COMMAND
Run Add New Command, or select Add New Command in Pocket AI Settings.
Pick Ask AI, Dictionary, Translator, Polish, or Blank Command as a template.
Customize its name, prompt, placeholders, and model, then save.
The new command is listed in Pocket AI Settings. The standalone
Add New Command launcher opens your new command immediately after saving.
Choose Add This Command to Raycast (or Add Command to Raycast in the manager)
to create a prefilled Quicklink. Assign that Quicklink your own alias/hotkey
in Raycast Settings > Quicklinks. It opens your command's input bar.

DEVELOPMENT
Source: your repository checkout or extracted source distribution.
Use install.ps1 for installation; see README.md and INSTALL-WINDOWS.txt.
The included run.ps1 finds a supported Node runtime:
  powershell -ExecutionPolicy Bypass -File .\run.ps1 Validate
  powershell -ExecutionPolicy Bypass -File .\run.ps1 Build
  powershell -ExecutionPolicy Bypass -File .\run.ps1 Develop
  powershell -ExecutionPolicy Bypass -File .\run.ps1 Bundle

The private local extension keeps its original internal ID for compatibility
with saved data and shortcuts. User-facing branding is Pocket AI.
The portable bundle is pocket-ai.rayext.
For another Windows PC, use pocket-ai-windows-source.zip and follow
INSTALL-WINDOWS.txt. The verified public Windows build (2.11.0.0) imports
extensions from source; direct .rayext bundle import is internal-only.
