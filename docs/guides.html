Your AI, in Raycast.

Pocket AI is an independent, open-source Raycast AI alternative. The extension is free; your provider's access requirements and costs still apply.

Use your own AI models in Raycast without Pro

  1. Install Raycast and Node.js 22.22.2+, then follow the Mac source guide or Windows installer guide.
  2. Open Pocket AI Settings > AI Provider. Enter your OpenAI-compatible base URL, such as https://api.example.com/v1, and its optional API key in the native password field.
  3. Open Ask AI. Choose Direct Model from Actions > Switch AI Backend, then select an advertised model from the top-bar dropdown.
  4. Type in the top input bar and press Enter. Continue with follow-up instructions in that same bar.

A separately configured VS Code Copilot bridge can be used if you already have one. Pocket AI does not include that bridge, grant Copilot access, or bypass a provider subscription. A localhost URL points to the machine running Raycast.

Use Hermes or OpenClaw from Raycast

  1. Run your own compatible Hermes API server or OpenClaw gateway. Make it reachable through a trusted connection, such as a private HTTPS/WSS ingress or your own loopback SSH tunnel.
  2. Open Pocket AI Settings > Remote Agents. Choose the backend and enter its server URL; only that backend's fields appear.
  3. Use its credential action to set the corresponding native password field. OpenClaw can also require device pairing on your gateway.
  4. Save, reopen Ask AI, and choose an advertised agent/profile. Switch backends from Actions or Command+Shift+B on Mac / Ctrl+Shift+B on Windows.

The harness owns models, web tools, memory, and execution. Leaving its view does not cancel accepted work. No transcript is automatically forwarded between backends, and an unsent draft is never automatically submitted during a switch.

Create custom AI shortcuts in Raycast

Start with Ask AI, Dictionary, Translator, or Polish. Assign an alias or hotkey in Raycast Settings. For example, assign df to Dictionary, then enter df, Space, a word, and Enter.

Use Customize This Tool to edit its prompt and input/follow-up placeholders. Set an explicit target language for Translator. For a new workflow, choose Add New Command, save a template, and use Add Command to Raycast to create a Quicklink with its own shortcut.

Rich Markdown and image URLs appear in the native preview. Full-Width Text provides automatic row following. Long rich previews use Raycast's native/manual scrolling; Pocket AI does not control that pane's internal scroll position.

Update a Mac source installation

Close Pocket AI views, open Terminal in your checkout, then run:

git pull --ff-only
npm ci
npm run build

Reopen Pocket AI. Source installations do not receive automatic Store updates.
